# ADR 0006：自由组坐标使用 `axis:"free" + Item.pos`

- **状态：** 已接受
- **日期：** 2026-11-05
- **决策者：** 架构组
- **相关：** SRS-M3STUDIO-001 V4.1 §5.2、§5.3、FR-M3-003/013、DC-036/DC-038

## 背景

M3E 用 `Group.free=true` 和 `Group.pos[itemId] = {x,y}` 保存自由组内各部件相对组的偏移。合并后的 `ScreenDoc` 需要：

- 与连接组（`axis:"x"`/`"y"`）区分；
- 支持拖动单个 Item 并持久化；
- 支持分组/取消分组/Tidy 后坐标可重复；
- 不把 M3E 的内部 map 结构泄漏为服务端主模型。

## 决策

1. `ScreenDoc` 中自由组用 `Group.axis:"free"` 表达。
2. 自由组内 `Item.pos = {x,y}` 为**屏幕本地绝对坐标**。
3. 非自由组禁止写入 `Item.pos`；坐标由 `Group.x/y`、`axis` 与 items 顺序推导（DC-036）。
4. `Group.pos = {x,y}` 保留为自由组的组锚点；与 `Group.x/y` 同值，便于编辑器整体拖动。
5. 导入 M3E：
   - `free:true + pos[itemId]` → `axis:"free"`；
   - `Item.pos = { groupLocalX + offset.x, groupLocalY + offset.y }`；
   - `Group.pos = { groupLocalX, groupLocalY }`。
6. 导出 M3E：
   - `axis:"free"` → `free:true`，`axis` 归一为 `"x"`；
   - `Group.pos[itemId] = { item.pos.x - groupWorldX, item.pos.y - groupWorldY }`；
   - 删除 `Item.pos`、`name/hidden/locked` 等服务端字段。
7. `hidden` 的组/Item 默认不导出；`includeHidden:true` 时才导出（DC-037）。
8. Tidy 不处理自由组与 `locked` 组；分组/取消分组/Tidy 后坐标归一不得依赖临时 UI 状态（DC-038）。

## 备选方案

| 方案 | 结论 | 原因 |
| --- | --- | --- |
| 直接沿用 `Group.pos[itemId]` map | 不采用 | 与 Item 级 API、patch、图层字段不一致；服务端模型被 M3E 内部结构绑死 |
| `Item.pos` 相对组坐标 | 不采用 | 组移动后需要批量改所有 Item；与“屏幕本地绝对坐标”语义冲突 |
| 非自由组也允许 `Item.pos` | 不采用 | 双坐标真源，Tidy 与连接组会漂移 |
| `axis:"free"` + 绝对 `Item.pos` | **采用** | 单坐标真源，拖动与 patch 简单，导入/导出可逆 |

## 后果

**正面**

- 拖动单个 Item 只需改一个 `Item.pos`。
- 自由组整体拖动只改 `Group.x/y` 与 `Group.pos`，Item 坐标不变（绝对坐标）。
- 导入/导出往返可保持相对偏移。

**负面 / 代价**

- 自由组的 M3E `axis`（x/y）信息在 ScreenDoc 中丢失；导出统一为 `"x"`。该字段只影响 M3E 的 run 拆分，不影响视觉。
- 需要额外校验：非自由组出现 `Item.pos` 必须报 `POS_NOT_ALLOWED`。
- 自由组整体拖动后，`Item.pos` 仍是绝对坐标，编辑器需同步组锚点。

## 验证

- `tests/m3-schema.test.mjs`：`axis:"free"`、`Item.pos` 允许/禁止、`Group.pos` 形状。
- `tests/m3-import-export.test.mjs`：自由组导入 → 导出偏移守恒。
- `scripts/m3-spike.mjs`：往返守恒。

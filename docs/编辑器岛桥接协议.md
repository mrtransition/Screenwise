# 编辑器岛桥接协议 v1

- **协议：** `m3studio/editor@1`
- **版本：** 1
- **状态：** M0 冻结
- **实现：** `apps/server/src/domain/m3/bridge.js`
- **测试：** `tests/m3-editor-bridge.test.mjs`
- **相关：** SRS-M3STUDIO-001 V4.1 §6.4、ADR 0001、ADR 0005

---

## 1. 适用范围

本协议只用于**宿主应用**与**M3 编辑器岛**（iframe 或独立窗口）之间的单屏编辑通信。

不在协议内：

- 项目级操作（建屏、删屏、排序、成员、主题修订）；
- 关联边编辑（由宿主侧关联模式处理）；
- AI 生成与 patch；
- 文件读写与版本落库。

这些能力由宿主 REST API 提供，编辑器岛不得直接调用。

---

## 2. 消息信封

所有消息必须是 JSON 对象，并带以下字段：

```json
{
  "protocol": "m3studio/editor@1",
  "request_id": "scr_ab12:load:1",
  "screen_id": "scr_ab12",
  "type": "load",
  "payload": {}
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `protocol` | string | 是 | 固定 `m3studio/editor@1` |
| `request_id` | string | 是 | 非空；同一次请求/响应建议复用 |
| `screen_id` | string | 是 | 必须是当前编辑屏；与会话不一致直接拒绝 |
| `type` | string | 是 | 见方向表 |
| `payload` | object | 是 | 按 `type` 校验 |

**约束**

- 单条消息序列化后 ≤ 5MB。
- 未知 `type` 拒绝。
- 方向不匹配拒绝（宿主消息不能伪装成岛消息，反之亦然）。

## 3. 宿主 → 编辑器岛

| type | payload | 说明 |
| --- | --- | --- |
| `load` | `{ doc, theme, design_tokens?, readonly, locked, locale?, measurements? }` | 加载单屏；`doc` 为 `ScreenDoc` |
| `theme` | `{ theme, design_tokens? }` | 主题热更新；不改变屏幕内容 |
| `mode` | `{ readonly, locked }` | 切换只读/锁定 |
| `flush` | `{}` | 请求立即提交未保存变更 |
| `fit` | `{}` | 适应画布 |
| `preview` | `{ startItemId? }` | 请求宿主打开预览 |

### `load` 示例

```json
{
  "protocol": "m3studio/editor@1",
  "request_id": "scr_ab12:load:1",
  "screen_id": "scr_ab12",
  "type": "load",
  "payload": {
    "doc": { "schema": "m3studio/screen@1", "format": "m3", "frame": {}, "groups": [] },
    "theme": { "dark": false, "bothModes": true, "contrast": "standard", "shape": "rounded", "font": "roboto", "emphasized": false, "motion": "standard" },
    "design_tokens": { "colors": { "primary": "#6750A4" } },
    "readonly": false,
    "locked": false,
    "locale": "zh-CN",
    "measurements": { "itm_title": 120 }
  }
}
```

## 4. 编辑器岛 → 宿主

| type | payload | 说明 |
| --- | --- | --- |
| `ready` | `{ protocol, version }` | 编辑器就绪；`version` 必须等于 1 |
| `change` | `{ doc, dirty, summary?, base_version }` | 变更（建议防抖 300ms）；宿主只更新草稿 |
| `save` | `{ doc, base_version, summary? }` | 用户显式保存；宿主校验并落库 |
| `select` | `{ item_ids?, group_ids? }` | 选区变化，用于宿主侧生成范围 |
| `preview` | `{ start_screen_id?, start_item_id? }` | 请求宿主打开预览 |
| `error` | `{ code, message, detail? }` | 编辑器内部错误 |
| `dirty` | `{ dirty }` | 离开前提示 |

### `save` 示例

```json
{
  "protocol": "m3studio/editor@1",
  "request_id": "scr_ab12:save:7",
  "screen_id": "scr_ab12",
  "type": "save",
  "payload": {
    "doc": { "schema": "m3studio/screen@1", "format": "m3", "frame": {}, "groups": [] },
    "base_version": 3,
    "summary": "调整卡片间距"
  }
}
```

## 5. 状态机

```
idle
  │ load
  ▼
loading ── ready ──► ready
  │                   │ change(dirty=true)
  │ timeout           ▼
  ▼                 dirty
stalled ◄─────────────┤
  │ retry(load)       │ save
  ▼                   ▼
loading             saving
                      │ ok
                      ▼
                    saved
                      │ change
                      ▼
                    dirty

任意状态 ── error/协议不兼容 ──► error
任意状态 ── close ────────────► closed
saving/ready ── base_version 过期 ──► conflict
```

| 状态 | 含义 | 可恢复 |
| --- | --- | --- |
| `idle` | 会话已创建，未加载 | 是 |
| `loading` | 已发送 `load`，等待 `ready` | 超时 → `stalled` |
| `ready` | 编辑器就绪，无未保存变更 | 是 |
| `dirty` | 有未保存草稿 | 是 |
| `saving` | 已提交 `save`，等待宿主结果 | 超时 → `stalled` |
| `saved` | 保存成功，版本已前进 | 是 |
| `conflict` | `base_version` 过期，拒绝覆盖 | 是（拉取新版本后合并） |
| `stalled` | 加载/保存超时 | 是（`retry` 重发 `load`） |
| `error` | 协议错误或编辑器内部错误 | 视错误而定 |
| `closed` | 会话关闭 | 否 |

**草稿保留规则**

- `change` 到达即保存为 `lastChange`。
- 进入 `conflict`、`stalled`、`error` 都不清空 `lastChange`。
- 只有 `save` 成功才清空草稿。

## 6. 安全校验

宿主必须执行：

1. `event.origin` 在白名单内；
2. `event.source` 是当前编辑器岛窗口；
3. `protocol` 精确匹配；
4. `screen_id` 与会话一致；
5. 消息大小 ≤ 5MB；
6. `save.doc` 通过 `validateScreenDoc`；
7. `base_version` 与当前版本一致；
8. 只读/锁定模式下拒绝 `save`（宿主侧业务规则）。

编辑器岛必须执行：

1. 只接受来自宿主窗口的消息；
2. 不把 `doc/theme` 发送给任何第三方；
3. 不持久化项目级密钥；
4. 不请求其他屏幕正文。

---

## 7. 错误码

| 错误码 | 触发 | 是否丢草稿 |
| --- | --- | --- |
| `BRIDGE_PROTOCOL_MISMATCH` | 协议版本、方向、字段、未知类型不匹配 | 否 |
| `BRIDGE_TIMEOUT` | `loading/saving` 超时 | 否 |
| `BRIDGE_CONFLICT` | `base_version` 过期或宿主返回冲突 | 否 |
| `SCHEMA_INVALID` | `ScreenDoc` 校验失败 | 否 |
| `SWIPE_DIRECTION_REQUIRED` | swipe 边缺 `direction`（导出/关联） | 不适用 |
| `CONFLICT` | 宿主业务层同屏并发 | 否 |

---

## 8. 版本兼容

- 协议版本升级时，`ready.payload.version` 必须变化。
- 宿主发现版本不兼容：进入 `error`，提示“编辑器版本不兼容”，**不得**静默降级。
- `ScreenDoc` schema 版本独立于桥接协议版本；两者都要校验。

## 9. 测试清单

`tests/m3-editor-bridge.test.mjs` 覆盖：

- 信封字段必填与方向校验；
- `load/change/save` 关键字段；
- `load → ready → change → save` 正常推进；
- `base_version` 过期 → 409 语义且保留草稿；
- 宿主返回冲突 → 保留草稿；
- 超时 → `stalled`，`retry` 重发 `load`；
- 保存超时保留最后一次 `change`；
- 协议版本不兼容、`screen_id` 不一致；
- 选区/预览/`dirty`；
- origin/source 校验与 5MB 上限。

## 4. 关键实现说明

### 4.1 数据模型

- `ScreenDoc` 严格禁止 `action/actions/frame.swipe`；
- `FlowEdge` 字段与 V4.1 一致，新增 `direction/expires_at`，移除持久化 `orphan`；
- `trigger` 白名单收敛为 `click/swipe/auto`；
- `Group.axis` 支持 `free`；自由组 `Item.pos` 为屏幕本地绝对坐标；
- `Group/Item` 支持 `name/locked/hidden`；`hidden` 默认不导出；
- 版本快照支持 `theme_snapshot` 与 `prompt_digest`。

### 4.2 导入/导出

- M3E `frame` → `ScreenDoc`，组坐标转屏幕本地；
- M3E `free + pos[itemId]` → `axis:"free" + Item.pos`；
- `action/actions` → `FlowEdge`（点击/slot）；
- `frame.swipe` → `FlowEdge`（`trigger:"swipe" + direction`）；
- 导出按 FlowEdge 投影回 `item.action/actions` 与 `frame.swipe`；
- 孤儿边与 candidate 边不导出；
- 同一屏同方向 swipe 冲突保留首条并告警 `EDGE_CONFLICT`；
- 导出确定性：边按稳定顺序排序。

### 4.3 桥接

- 协议 `m3studio/editor@1`；
- 状态机 `idle/loading/ready/dirty/saving/saved/conflict/stalled/error/closed`；
- `base_version` 冲突不覆盖，草稿保留；
- 超时进入 `stalled`，`retry` 重发 `load`；
- origin/source 校验与 5MB 上限。
